# Roadmap

One feature ships per day (1 pm UK time), top priority first. Tick the box when done.

- [x] 1. **Daily streaks + daily challenge** (top feature): a fresh seeded puzzle each day ("win as 🐰 in 2 moves"), a streak counter, and a streak-freeze. Stored in localStorage.
- [x] 2. **Play vs computer**: easy / medium / unbeatable (minimax) so there is always an opponent.
- [ ] 3. **Player names + per-player stats and Elo ranking**: replaces the species-only leaderboard with a ranked ladder.
- [ ] 4. **Achievements and badges**: "Hat-trick" (3 wins in a row), "Comeback", "Perfect week", and so on.
- [ ] 5. **Best-of-3 / best-of-5 series mode** with a match scoreboard and rematch button.
- [ ] 6. **Game feel**: win-line animation, confetti, sound effects, mute toggle, reduced-motion support.
- [ ] 7. **Share card + weekly seasons**: Wordle-style copyable result, weekly leaderboard reset with a "season champion".
